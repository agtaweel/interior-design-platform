# دليل مسؤول المنصة (Platform Owner) — Fitout

هذا الدليل منفصل عن [دليل استخدام المؤسسة والعميل](USER_GUIDE_AR.md) لأن مستوى **"مسؤول المنصة"** مختلف تمامًا: هو حساب **واحد يرى كل المؤسسات المسجَّلة على Fitout في نفس الوقت** — وليس عضوًا داخل أي مؤسسة بعينها.

## ما هو "مسؤول المنصة" بالضبط؟

- طبقة **تحليلات للقراءة فقط**، عابرة لكل المؤسسات (cross-tenant).
- **لا يوجد فيها**: تعديل أو حذف بيانات أي مؤسسة، لا انتحال هوية مستخدم (Impersonation)، لا إدارة اشتراكات أو فوترة، ولا اطّلاع على سجل النشاط التفصيلي لأي مؤسسة. فقط أعداد وملخصات مالية مجمّعة.
- لا توجد أي طريقة داخل المنصة (لا زر ولا نموذج) لمنح هذه الصلاحية لأي حساب — هذا مقصود أمنيًا: لا يمكن منحها إلا من له وصول مباشر لخادم التطبيق (راجع "منح الصلاحية لحساب آخر" أدناه).

## بيانات الدخول

تم إنشاء حساب مسؤول منصة ثابت عبر Seeder مخصص (`PlatformAdminSeeder`) — يعمل تلقائيًا عند إعداد قاعدة بيانات جديدة، ولا يحتاج أي خطوة يدوية إضافية.

| الحقل | القيمة |
|---|---|
| البريد الإلكتروني | `admin@fitout.example` |
| كلمة المرور | `FitoutAdmin#2026` |

سجّل الدخول بهما من نفس شاشة تسجيل الدخول العادية للمنصة — بمجرد الدخول، سيظهر تبويب إضافي باسم **"المنصة"** في القائمة العلوية لا يظهر لأي عضو مؤسسة عادي.

> ⚠️ **تنبيه أمني مهم**: هذه بيانات دخول ثابتة موجودة في الكود ومكتوبة في هذا الملف — مناسبة تمامًا لبيئة تجريبية (Demo)، لكن **يجب تغيير كلمة المرور فورًا** قبل استخدام هذا الحساب في أي بيئة حقيقية يطّلع عليها أشخاص خارج فريقك. غيّرها من داخل قاعدة البيانات مباشرة أو أضف مسارًا لتغيير كلمة المرور لهذا الحساب تحديدًا.

## تسجيل الدخول وأول شاشة

بعد تسجيل الدخول، اضغط تبويب **"المنصة"** لفتح **نظرة عامة على المنصة**، وتعرض:

- **4 بطاقات رئيسية**: عدد المؤسسات، عدد المشاريع، عدد المستخدمين، وإجمالي المستحقات عبر كل المؤسسات.
- **بطاقة "البيانات المالية للمنصة"**: الالتزام الإجمالي (Obligation)، المحصَّل، المستحق، التكلفة الفعلية، وإجمالي الربح — كلها مجمّعة عبر كل المؤسسات معًا.
- **"المشاريع حسب الحالة"**: عدد المشاريع في كل حالة (نشط/مسودة/متوقف/مكتمل/ملغى) عبر كل المنصة.
- **قائمة كل المؤسسات المسجَّلة**: الاسم، عدد المشاريع، عدد الأعضاء، والعملة — اضغط على أي مؤسسة للدخول لتفاصيلها.

## تفاصيل مؤسسة واحدة

بالضغط على أي مؤسسة من القائمة، تفتح صفحة تعرض **نفس نوع البيانات أعلاه لكن محصورة في هذه المؤسسة فقط**: اسمها القانوني، عملتها، تاريخ انضمامها، عدد مشاريعها وأعضائها، مستحقاتها، وإجمالي ربحها، بالإضافة إلى توزيع مشاريعها حسب الحالة.

كل شيء في هاتين الشاشتين **للقراءة فقط** — لا يوجد أي زر تعديل أو حذف أو إجراء على أي مؤسسة من هنا.

## منح صلاحية "مسؤول المنصة" لحساب آخر

إذا احتجت لاحقًا منح هذه الصلاحية لمستخدم حقيقي (بدلًا من أو بالإضافة إلى الحساب الافتراضي أعلاه)، لا يوجد زر لذلك في الواجهة عمدًا. الطريقة الوحيدة هي أمر Artisan من الخادم مباشرة، بعد إنشاء الحساب بشكل عادي (تسجيل/دعوة):

```
php artisan platform:owner user@example.com
```

ولسحب الصلاحية:

```
php artisan platform:owner user@example.com --revoke
```

## إعادة تشغيل حساب مسؤول المنصة الافتراضي يدويًا

إذا احتجت إعادة إنشاء الحساب الافتراضي أعلاه (مثلًا بعد قاعدة بيانات جديدة تمامًا لم يُشغَّل عليها الإعداد الكامل بعد):

```
php artisan db:seed --class=PlatformAdminSeeder
```

هذا الأمر آمن للتشغيل أكثر من مرة (لا يُنشئ نسخًا مكررة، ولا يمسح أي بيانات) — سواء محليًا داخل حاويات Docker أو على أي بيئة منشورة (Northflank/Render/إلخ)، حيث يعمل تلقائيًا أيضًا عند كل إقلاع للحاوية.
